### 4.1 Conversion Window

This window allows the batch conversion of multiple `.mpa` files
contained in a selected folder.

The software processes all `.mpa` files in the chosen directory and
converts them into structured `.txt` files.

The conversion includes: - Extraction of raw acquisition data - Dead
time calculation - Separation of data for each ADC channel -
Initialization and formatting of the output data

#### User Actions

1.  Select the input folder
    -   The folder must contain the `.mpa` files generated by the MPA
        acquisition software.\
    -   The path can be entered manually or selected using the
        **"Browse"** button.
2.  Select the output folder (optional)
    -   The user may choose where the converted `.txt` files will be
        saved.\
    -   If no output path is specified, the converted files will be
        stored in a temporary working directory for the duration of the
        current session. [TODO: Check this part
        later]{style="color:red"}
    -   Each `.mpa` file will generate one `.txt` file per ADC channel
        following the naming convention described above.

Once the input folder is defined, the batch conversion process can be
launched.

#### Output Text File Structur

For each `.mpa` file contained in the selected folder, the software
generates one output `.txt` file per ADC channel.

The naming convention is:

filename_adcname.txt

**File naming:** `filename_ADCname.txt` - `filename` : name of the
original `.mpa` file - `ADCname` : ADC channel identifier

Example:

If the input file is: sample01.mpa

And it contains ADC1 and ADC2,

The generated files will be: sample01_ADC1.txt sample01_ADC2.txt

**File content / Structure:** 1. **Header line:** - Indicates the
calculated dead time factor for this ADC channel.

2.  **Data lines:**\

-   `Channel`: ADC channel number or identifier\
-   `Count`: measured counts for each sample

**Notes:** - Each `.mpa` file generates one `.txt` file per ADC
channel.\
- All files are formatted for direct analysis in Python, or other data
processing software.

### 4.2 Calibration

This window allows the user to perform a calibration from a `.txt` file
generated in the Conversion window.

The user can select a text file, then for each chosen peak(s):

1.  Identify the approximate position of the peak by clicking on it.
2.  Fit a Gaussian function to the selected peak to determine its
    centroid.
3.  Calculate a linear regression between the ADC channel numbers and
    the corresponding energy values of the chosen peaks.

The result is a calibration curve that maps channels to energy values
for subsequent analyses.

### 4.3 Processing

This window allows the user to perform all the steps of the data
processing workflow.

1.  **Loop over ROI (Region of Interest):**
    -   For a given ROI in energy, the program counts the number of
        counts and normalizes it by the integrated charge.\
    -   This produces the excitation profile for the selected ROI.
2.  **Eject peak (optional):**
    -   For a given energy, the software searches for peaks in the
        output of the loop within a specified interval (ΔE = 200 keV by
        default).\
    -   Points corresponding to peaks within another specified interval
        fix (20 keV by default) can be removed if necessary.\
        [Can be change easily do an explenation how with change in the
        code and see if it works]{style="color:red"}
3.  **Sigmoid fit:**
    -   Once the loop is complete (and peaks optionally ejected), the
        software performs a sigmoid fit on the resulting data.\
    -   It calculates the difference between the high and low plateaus
        and assigns a group to each profile.
